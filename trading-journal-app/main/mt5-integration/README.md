# MT5 Integration

Esta carpeta contiene los recursos para la integración con MetaTrader 5.

- `mt5_fetch.exe`: Ejecutable Python para obtener datos de cuentas y trades desde MT5.
- `mt5_fetch.py`: Script fuente (opcional, solo para desarrollo).

Coloca aquí el ejecutable generado con PyInstaller y cualquier documentación técnica relevante.
